## 1. 상단 헤더 와이어프레임 (Header & Google Social Login)

모든 페이지 상단에 고정(`sticky top-0`)되는 글로벌 헤더로, 로그인 여부에 따라 우측 영역이 동적으로 전환됩니다. 로그인 시 표시 이름(`displayName`)은 이메일의 `@` 앞부분을 사용합니다.

### 1.1 비로그인 상태 헤더
```text
+-----------------------------------------------------------------------+
|  [⚡ mylink]   [프로필]  [전체 링크]            [G Google 로그인] [🐙] |
+-----------------------------------------------------------------------+
```

### 1.2 로그인 완료 상태 헤더
```text
+-----------------------------------------------------------------------+
|  [⚡ mylink]   [프로필]  [전체 링크]   [(👤) user | user@...] [로그아웃] |
+-----------------------------------------------------------------------+
```

## 2. 비로그인 상태 화면 와이어프레임 (Login Required View)

로그인하지 않은 방문자가 메인 페이지(`/`) 또는 전체 링크 페이지(`/links`)에 접속했을 때 표시되는 안내 화면입니다. 로그인 이후에 서비스를 사용할 수 있음을 안내하고 즉시 Google 로그인을 수행할 수 있습니다.

```text
+-------------------------------------------------------------+
|                     [ 📱 모바일/웹 뷰포트 ]                 |
+-------------------------------------------------------------+
|  [⚡ mylink]   [프로필]  [전체 링크]        [G Google 로그인] |  <- 상단 헤더
+-------------------------------------------------------------+
|                                                             |
|   +-----------------------------------------------------+   |
|   |                 [ 🔒 LOGIN REQUIRED ]               |   |  <- 상단 스티커 배지
|   |                                                     |   |
|   |                      /-------\                      |   |
|   |                     |   🔒   |                      |   |  <- 자물쇠 아이콘 배지
|   |                      \-------/                      |   |
|   |                                                     |   |
|   |          [ ✦ 마이링크 프로필 카드 ]                 |   |
|   |         로그인 이후에 사용할 수 있습니다            |   |  <- 안내 헤딩
|   |                                                     |   |
|   |  +-----------------------------------------------+  |   |
|   |  | 마이링크(MyLink)는 Google 소셜 로그인 이후에  |  |   |  <- 로그인 필요 설명 문구
|   |  | 사용할 수 있는 개인화 프로필 & 링크 관리      |  |   |
|   |  | 서비스입니다.                                 |  |   |
|   |  | 상단 헤더의 [Google 로그인] 버튼 또는 아래    |  |   |
|   |  | 버튼을 눌러 로그인하시면 나만의 프로필 정보와 |  |   |
|   |  | 소중한 링크들을 안전하게 관리할 수 있습니다.  |  |   |
|   |  +-----------------------------------------------+  |   |
|   |                                                     |   |
|   |  +-----------------------------------------------+  |   |
|   |  | [👤] 내 프로필 정보 자동 연동                 |  |   |
|   |  |      아이디(이메일 앞부분), 이메일, 사진 표시 |  |   |
|   |  +-----------------------------------------------+  |   |
|   |  +-----------------------------------------------+  |   |
|   |  | [🔗] 개인화된 링크 관리                       |  |   |
|   |  |      계정별 독립 공간에 나만의 링크 저장/관리 |  |   |
|   |  +-----------------------------------------------+  |   |
|   |                                                     |   |
|   |  -------------------------------------------------  |   |
|   |                                                     |   |
|   |  +-----------------------------------------------+  |   |
|   |  |       [G]  Google 계정으로 로그인하기         |  |   |  <- 메인 로그인 CTA 버튼
|   |  +-----------------------------------------------+  |   |
|   +-----------------------------------------------------+   |
|                                                             |
+-------------------------------------------------------------+
```

## 3. 로그인 후 메인 화면 와이어프레임 (Personalized Profile Card View)

Google 소셜 로그인을 완료한 사용자가 보게 되는 개인화된 프로필 카드 뷰입니다. 이메일 앞부분(`displayName`), 이메일, 프로필 사진 및 개인화된 링크 목록이 화면에 렌더링됩니다.

```text
+-------------------------------------------------------------+
|                     [ 📱 모바일 뷰포트 ]                    |
+-------------------------------------------------------------+
|  [⚡ mylink]  [프로필] [전체 링크]   [(👤) user ▾] [로그아웃] |  <- 로그인된 헤더
+-------------------------------------------------------------+
|                                                             |
|   +-----------------------------------------------------+   |
|   | [샘플 10개]                         [ ✦ OPEN TO WORK ]  |  <- 상단 뱃지/스티커
|   |                                                     |   |
|   |                    /-----------\                    |   |
|   |                   |  [아바타]  | (● 활동중)         |   |  <- Google 프로필 사진
|   |                    \-----------/                    |   |
|   |                                                     |   |
|   |                       u s e r                       |   |  <- 이메일 앞부분 (Heading)
|   |   [ ● Frontend Developer ]  [ 📧 user@gmail.com ]   |  <- 직무 뱃지 & 이메일
|   |                                                     |   |
|   |     직관적인 사용자 경험과 클린 코드를 지향하는     |   |  <- 소개글 (Bio)
|   |     웹 개발자입니다. 새로운 기술을 탐구하고         |   |
|   |     일상의 가치를 높이는 서비스를 만듭니다.         |   |
|   |                                                     |   |
|   |  === [ ✦ 내 링크 목록 (N개) ] === [+ 새 링크 추가]  |   |
|   |                                                     |   |
|   |  +-----------------------------------------------+  |   |
|   |  | [🐙]  GitHub 방문하기        [↗] [수정][삭제] |  |   |  <- 링크 버튼 + 인라인 액션
|   |  +-----------------------------------------------+  |   |
|   |                                                     |   |
|   |  +-----------------------------------------------+  |   |
|   |  | [⭐]  my-Link-k 프로젝트     [↗] [수정][삭제] |  |   |
|   |  +-----------------------------------------------+  |   |
|   |                                                     |   |
|   |  -------------------------------------------------  |   |
|   |                                                     |   |
|   |          [GitHub]    [Instagram]    [Email]         |   |  <- 소셜 아이콘 바
|   |                                                     |   |
|   |       [#React]  [#Next.js]  [#Tailwind]  [#UX]      |   |  <- 키워드 태그
|   +-----------------------------------------------------+   |
|                                                             |
+-------------------------------------------------------------+
```

## 4. 새 링크 추가 & 인라인 편집 와이어프레임 (Editor View)

소유자가 `[+ 새 링크 추가]` 버튼 또는 각 링크의 `[수정]` / `[삭제]` 버튼을 클릭했을 때 열리는 모달 및 인라인 편집 폼입니다.

```text
+-------------------------------------------------------------+
|  +-------------------------------------------------------+  |
|  |  [✦ NEW LINK]                                     [X] |  |  <- 모달 헤더
|  |  새 링크 추가하기                                     |  |
|  +-------------------------------------------------------+  |
|  |                                                       |  |
|  |  아이콘 (이모지) *                                    |  |
|  |  [ 🔗 ]  [🐙] [⭐] [📝] [💼] [🚀] [📬] [📸] [🎨] [💻] |  |
|  |                                                       |  |
|  |  링크 제목 *                                  (0/50자)|  |
|  |  +-------------------------------------------------+  |  |
|  |  | 예: 개인 포트폴리오 웹사이트                    |  |  |
|  |  +-------------------------------------------------+  |  |
|  |                                                       |  |
|  |  URL 주소 *                                           |  |
|  |  +-------------------------------------------------+  |  |
|  |  | https://github.com/...                          |  |  |
|  |  +-------------------------------------------------+  |  |
|  |                                                       |  |
|  |  한줄 설명 (선택)                             (0/80자)|  |
|  |  +-------------------------------------------------+  |  |
|  |  | 링크에 대한 간단한 설명을 적어주세요            |  |  |
|  |  +-------------------------------------------------+  |  |
|  |                                                       |  |
|  |  카테고리                            [📌 상단 PIN 고정]|  |
|  |  [개발] [프로젝트] [블로그] [포트폴리오] [소셜] [연락처]|  |
|  |                                                       |  |
|  +-------------------------------------------------------+  |
|  |                                  [ 취소 ] [ + 링크 추가 ]|  |
|  +-------------------------------------------------------+  |
+-------------------------------------------------------------+
```

## 5. 영역별 UI 컴포넌트 및 스타일 매핑 (`@base-ui/react` & Neobrutalism)

| 화면 영역 | 사용 컴포넌트 (`src/components/ui/`) | 주요 시각적 특징 및 인터랙션 (`prd.md` / `design.md`) |
| :--- | :--- | :--- |
| **상단 헤더 & 소셜 로그인** | `Header`, `Button`, `Avatar`, `Menu`, `Badge` | 비로그인 시 `[Google 로그인]` 버튼 노출, 로그인 시 아바타·이메일 앞부분(`displayName`)·이메일 및 `[로그아웃]` 버튼 노출 |
| **비로그인 안내 카드** | `LoginRequiredCard`, `Card`, `Button`, `Badge` | 미인증 상태 접속 시 로그인 이후 사용 가능함을 알리는 상세 설명 문구 및 Google 로그인 CTA 버튼 제공 |
| **메인 컨테이너** | `Card`, `CardHeader`, `CardContent`, `CardFooter` | 굵은 검은색 테두리(`border-3 border-black`), 하드 그림자(`shadow-[6px_6px_0px_#000000]`) |
| **상단/직무 뱃지** | `Badge` | 민트그린(`#A7F3D0`) 또는 스카이블루(`#BAE6FD`) 배경, 펄스(Pulse) 상태 점, `shadow-[2px_2px_0px_#000000]` |
| **아바타** | `Avatar`, `AvatarImage`, `AvatarFallback` | `@base-ui/react/avatar` 기반 Google 계정 프로필 사진(`user.photoURL`) 연동, 원형 프레임, 우측 하단 온라인 활동 인디케이터 |
| **소개글 (Bio)** | `CardDescription` | 멀티라인 자기소개 텍스트, 높은 가독성의 순수 블랙(`#000000`) 타이포그래피 |
| **링크 버튼 목록** | `LinkButton`, `Button`, `Fieldset` | 좌측 아이콘(이모지) + 중앙 제목 + 우측 화살표(`↗`) 및 `[수정]`/`[삭제]` 버튼 |
| **구분선** | `Separator` | `@base-ui/react/separator` 기반 순수 블랙(`#000000`) 분할선 |
| **소셜 아이콘 바** | `Button` (`size="icon"`) | GitHub, Instagram, Email(로그인 유저 이메일 연동) 등 아이콘 버튼 |
| **키워드 태그** | `Badge` (`variant="tag"` 등) | `#React`, `#Next.js`, `#Tailwind`, `#UX` 해시태그 나열 |
| **추가/삭제 모달** | `Dialog`, `Input`, `Button`, `Field` | `@base-ui/react/dialog`, `@base-ui/react/field`, `@base-ui/react/input` 기반 새 링크 추가 및 삭제 확인 모달 제공 |
